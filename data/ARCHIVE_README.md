# 9359 上市櫃歷史資料

2026-09-27 首次回補：2023-05-23 至 2026-09-24，815 個有效日期、1,991 個證券代號、112,954 筆日期×證券紀錄。E/B 兩模式均可見者 50,046 筆；其他保留缺值。58 個平日無有效日期頁面，詳見 source_audit.csv。1,630 個有效原始頁面雜湊與 SQLite 完整性已核對；舊 CSV 重疊 3,867 筆淨張數全部一致。這是觀察資料完整性檢查，不代表全市場或分點全部交易均被涵蓋。

`archive_9359/9359.sqlite` 是本機研究資料庫，原始回應保存於 `archive_9359/raw/YYYY/`，不提交 GitHub。

- `ranking`：富邦頁面的逐日公開排行；鍵為日期、模式、股票。E 的數字為張數，B 為千元，兩者不可相加。
- `pages`：每個請求的日期、模式、結果、筆數、原始回應雜湊及擷取時間。日期不符與 HTTP 失敗可續跑重試。
- `local_top3`：本機舊 CSV 的個股買賣超前三名紀錄，僅作獨立核對，不當作完整分點庫存。

來源為公開排行榜，**未上榜不等於沒有交易**。E/B 應按日期、股票外連接，缺少的模式保持 NULL，不補零；B 金額轉新台幣需乘 1,000。不能由此直接聲稱已知真實持股、完整成本或精確資金留存。

回補指令：`python scripts/archive_9359.py --start 2023-05-23 --end 2026-09-24`。已成功的頁面會跳過。歷史休市日或來源日期不符仍列為缺漏，不能據此推定買賣為零。

本機每日 BAT 在價格日期檢查通過後，從上次保存日期補抓至當日，與網站的 20 日展示資料分開保存。回補按週一至週五枚舉日期，休市頁面照實記錄為未取得有效資料。回測前須檢查完整性，並將策略界定為可觀察排行榜訊號，或補齊個股分點明細後再測庫存型策略。

`python scripts/import_local_rankings.py` 匯入舊 CSV；`python scripts/export_archive.py` 匯出保留空值的 `9359_observed_daily.csv`、逐頁 `source_audit.csv` 及涵蓋率與交叉驗證報告 `coverage.json`。
